# Attribution and source boundaries

This skill was written for this package. It uses high-level concepts from the following sources, but does not copy their skill text, recipes, detector rules, or code.

| Source | Upstream license | Concepts used as design input |
|---|---|---|
| Emil Kowalski, [emilkowalski/skills](https://github.com/emilkowalski/skills) | MIT | Purposeful motion, interaction fit, and a focused animation decision process. |
| Paul Bakaus, [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | Apache-2.0 | Separate craft, critique, audit, polish, and distillation; use bounded review passes. |
| Leonxlnx, [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | MIT | Optional design variance, motion intensity, and visual density dials; resist repetitive generic layouts. |

The current Taste Skill README describes its default v2 design skill as experimental. This package does not depend on its implementation or prescribe its specific stylistic rules.

The portable skill structure follows the [Agent Skills format](https://agentskills.io/specification) and Anthropic's [Claude Code skill documentation](https://code.claude.com/docs/en/skills). W3C WCAG/APG, MDN, and web.dev are cited as technical references in the relevant files.
