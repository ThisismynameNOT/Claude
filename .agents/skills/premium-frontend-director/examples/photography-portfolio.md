# Example: premium photography portfolio

## Brief

Create an image-led portfolio that helps visitors understand the photographer's work and reach the appropriate contact or booking action.

## Direction

Use **Experience** for image sequencing and large work samples; use **Persuade** for biography, services, and contact. Let real photography lead the art direction. Avoid decorative UI that competes with the images.

## Implementation cues

- Preserve image quality and useful crop choices across mobile and desktop.
- Provide semantic captions and meaningful alternative text where an image conveys content.
- Use motion only to clarify sequencing or transitions; respect reduced motion and prevent controls from disappearing on touch devices.
- Set dimensions and loading behavior to limit layout shifts and keep the first meaningful image responsive.

## Acceptance evidence

Check gallery navigation with keyboard and touch, first-load rendering on mobile, image crop, contact flow, reduced motion, and loading behavior. Do not claim rights to images without source confirmation.
